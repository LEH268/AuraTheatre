# Aura Theatre 🎬

[cite_start]Aura Theatre is a movie information hub developed for the **WEB1201 / WEB2014 Web Fundamentals** course at **Sunway University**[cite: 1, 2]. [cite_start]It serves as a centralized platform for users to discover and explore details about movies, cartoons, and anime[cite: 27, 76].

## 📌 Project Overview
[cite_start]The website aims to provide users with convenient access to movie information, including titles, genres, release years, synopses, and ratings[cite: 29, 31]. [cite_start]It targets a wide audience range, from teenagers to older adults[cite: 33].

* [cite_start]**Academic Session:** September 2025 Semester[cite: 2].
* [cite_start]**Group:** 999[cite: 3].
* [cite_start]**Demo Video:** [Watch on YouTube](https://youtu.be/ZTYYzHOI2Zg)[cite: 25].

## ✨ Key Features
* [cite_start]**Neon Cyberpunk Aesthetics:** A visually immersive design using dark backgrounds to reduce eye strain and high-contrast neon accents for readability[cite: 47, 48, 49].
* [cite_start]**Automated Movie Carousel:** A timer-based recommendation slider that automatically rotates movie posters every 3 seconds to enhance engagement[cite: 62, 63, 122].
* [cite_start]**User Authentication Simulation:** Functional Sign Up and Login pages featuring form validation to simulate real-world access control[cite: 55, 56, 80].
* [cite_start]**Interactive Contact Form:** A dedicated feedback section where the submit button is dynamically enabled only after valid data entry[cite: 71, 72, 116].
* [cite_start]**Categorized Navigation:** Content is separated into specialized pages for Movies, Cartoons, and Anime to improve search efficiency[cite: 76, 77].
* [cite_start]**Responsive Design:** Optimized for various devices, including laptops and tablets, using CSS Grid and flexible layouts[cite: 44, 155].

## 🛠️ Technical Stack
[cite_start]The project was built using vanilla web technologies to demonstrate a solid foundation in web development[cite: 107]:
* [cite_start]**HTML5:** Structured content and hierarchical elements[cite: 35, 85].
* [cite_start]**CSS3:** Styling, neon visual effects, and responsive grid layouts[cite: 35, 44].
* [cite_start]**JavaScript:** DOM manipulation, automated timers, and form validation using Regular Expressions[cite: 35, 62, 159].
